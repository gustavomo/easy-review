    **Step 2 — Implement directoryTree.ts.**

    Create `src/easy-review/utils/directoryTree.ts`. Port the upstream `DirectoryTreeNode` algorithm as a pure function.

    Algorithm:
    1. Build a mutable tree of `DirectoryNode` objects starting from a virtual root `DirectoryNode('')`
    2. For each file, split `filename` by `/`, walk the path segments creating `DirectoryNode` children as needed, place a `FileNode` at the leaf
    3. After all files are placed, compact single-child directory nodes: if a `DirectoryNode` has exactly one child that is also a `DirectoryNode`, merge labels with `/` separator and adopt grandchildren (repeat until no single-child dirs remain)
    4. Sort each `DirectoryNode`'s children: `DirectoryNode` instances before `FileNode` instances; within each group, sort alphabetically by label
    5. If the root node has label `''`, return `root.children` directly (flatten root); otherwise return `[root]`

    Signature:
    ```typescript
    export function buildDirectoryTree(
      files: PRFileChange[],
      pr: StoredPR,
    ): EasyReviewTreeNode[]
    ```
