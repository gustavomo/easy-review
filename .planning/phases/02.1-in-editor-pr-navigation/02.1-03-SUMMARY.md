## Accomplishments

- `diffUri.ts`: `encodeDiffUri` builds `easy-review-diff://<owner>+<repo>/<path>?ref=<sha>&label=<label>` URI; `decodeDiffUri` extracts components back
- `EasyReviewDiffProvider.ts`: `TextDocumentContentProvider` that fetches file content from GitHub REST API via `octokit.rest.repos.getContent`
- Wave 0 stubs replaced with 7 real round-trip tests covering: normal path, spaces in label, EMPTY sentinel, deep path, renamed file, scheme check, authority format
- `Uri.from` added to vscode mock for test environment URI construction
- EMPTY sentinel prevents any API call for added/removed files (returns '' immediately)
- `encoding:'none'` guard for files >1MB returns human-readable placeholder
- Base64 decode strips GitHub's newline padding before `Buffer.from`
- In-memory cache prevents double-fetch when VS Code calls provider twice per diff view
