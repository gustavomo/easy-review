## Decisions Made

- **ready/loadPR handshake over setTimeout:** The webview posts `{ type: 'ready' }` on mount; the extension host replies with `{ type: 'loadPR', pr: ... }`. This eliminates the race condition where `postMessage` fires before the webview's event listener is registered.
- **type=module + cspSource CSP fix:** VS Code Vite-built webviews use ES modules. The `<script>` tag requires `type="module"` and the CSP `script-src` must include `${webview.cspSource}` (not just `'nonce-${nonce}'`). Applied to both PROverviewPanel and ReviewPanel.
- **Not a singleton:** `PROverviewPanel.open()` always creates a fresh panel — no `currentPanel` guard — consistent with D-14 design note.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Replaced setTimeout race with ready/loadPR message handshake**
- **Found during:** Task 1 (PROverviewPanel.ts first implementation)
- **Issue:** Using `setTimeout(100ms)` to delay `postMessage` is a race condition — webview may not have registered its listener in time, especially in slower VS Code instances
- **Fix:** Webview posts `{ type: 'ready' }` on mount; extension host listens for it and replies with `{ type: 'loadPR', pr: ... }`
- **Files modified:** src/easy-review/panel/PROverviewPanel.ts, src/webview/prOverview.tsx
- **Verification:** Human verification confirmed panel loads PR data correctly
- **Committed in:** 289aba71

**2. [Rule 1 - Bug] Added type=module + cspSource to CSP for ES module script loading**
- **Found during:** Task 1 (manual verification in Extension Development Host)
- **Issue:** Vite produces ES module bundles. Without `type="module"` on the `<script>` tag and `${webview.cspSource}` in script-src, VS Code's CSP blocks module script execution — the webview panel was blank
- **Fix:** Added `type="module"` to `<script>` tag in getWebviewHtml(); added `${webview.cspSource}` to script-src CSP directive. Applied to both PROverviewPanel.ts and ReviewPanel.ts for consistency
- **Files modified:** src/easy-review/panel/PROverviewPanel.ts, src/easy-review/panel/ReviewPanel.ts, src/easy-review/activation.ts
- **Verification:** Human verification confirmed both review panel and PR overview panel load correctly
- **Committed in:** 103b00ed
