## Decisions Made

- Parsers return `null` (not empty array) when no `###` headings found — caller can reliably distinguish "structured parse succeeded" from "no structure, fall back to marked()" with a simple null check
- `detectImpact` scans all bodyLines joined as lowercase — handles `High impact`, `HIGH impact`, or impact keyword embedded anywhere in dimension body text
- `hasHighBreaking` requires both `name.includes('breaking')` (case-insensitive) and `impact === 'high'` — prevents false positives from other dimensions that happen to be high impact
