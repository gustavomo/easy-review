## What Was Built

**Task 1 — Packages + Global Wiring:**
- Installed `highlight.js@^11.11.1` and `marked-highlight@^2.2.3` as production dependencies (with `--legacy-peer-deps` due to vitest peer dep conflict in the project)
- Added `import { markedHighlight } from 'marked-highlight'` and `import hljs from 'highlight.js'` to `ReviewDocument.tsx`
- Added `marked.use(markedHighlight({...}))` at module level (before the `ReviewDocument` component function) — applies to all existing `marked(section.content ?? '')` calls without any per-call changes
- `emptyLangClass: 'hljs'` ensures language-less code blocks still receive the `.hljs` class
- `hljs.highlightAuto(code).value` fallback provides auto-detection for untagged blocks (D-03)

**Task 2 — CSS Token Colors + Table Styles:**
- Added `.easy-review-md .hljs` base rule with `vscode-textCodeBlock-background` and `vscode-editor-foreground` (D-04)
- Added token-specific color rules for: keyword/selector-tag, string/attr, comment, number/literal, title/name/class/type, variable/params, built_in, function — all using VS Code CSS vars with fallback hex values
- Added markdown table styles: `border-collapse: collapse`, `width: 100%`, `display: block`, `overflow-x: auto` on `.easy-review-md table`
- Striped rows via `tbody tr:nth-child(odd) td` using `vscode-list-hoverBackground` (D-19/D-20)
- Header row uses `vscode-editorGroupHeader-tabsBackground` background
- Cell borders use `vscode-panel-border`
- All new rules are additive — the existing `.easy-review-md pre code { background: none; padding: 0; }` rule at line 33 is unchanged
