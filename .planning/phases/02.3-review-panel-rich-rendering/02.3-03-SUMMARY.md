## Decisions Made

- **--legacy-peer-deps for mermaid install:** @opentelemetry/api peer conflict between mermaid and vitest@4.1.2 requires --legacy-peer-deps; not a runtime issue.
- **module-level mermaid.initialize():** Placing inside component would re-initialize on every render (Pitfall 5). Module-level ensures single initialization per webview load.
- **securityLevel: 'loose':** Required by mermaid v11 when using unsafe-eval CSP. Without this, mermaid silently fails to render.
- **chunkSizeWarningLimit: 4000:** Mermaid adds ~2-3MB to the bundle. The default 500KB limit would spam build output with warnings.
