    The runAllAgents() function signature:
    ```typescript
    export interface OrchestratorOpts {
      diff: string;
      fileList: string;
      modelConfig: ModelConfig;      // from modelSettings.ts
      claudePath: string;
      codexPath: string;
      projectAnalysis?: string;      // from SQLiteStore (if any agent requests it)
      commitHistory?: string;        // from GitHub (if any agent requests it)
      token: vscode.CancellationToken;
      onSectionUpdate: (agentKey: AgentKey, state: SectionState) => void;
    }

    export interface OrchestratorResult {
      sections: Record<AgentKey, SectionState>;
    }

    export async function runAllAgents(opts: OrchestratorOpts): Promise<OrchestratorResult>
    ```

    Implementation structure:

    1. Define AGENT_ORDER: AgentKey[] = ['prSummarizer', 'bugRisk', 'architectureChange', 'testCoverage', 'documentation', 'diagram', 'businessImpact']

    2. Import all 7 agent modules and a map from AgentKey to their getSystemPrompt/getTemplate:
    ```typescript
    import * as PRSummarizerAgent from './PRSummarizerAgent';
    // ... all 7 agents
    const AGENT_MAP: Record<AgentKey, { getSystemPrompt(): string; getTemplate(opts: AgentTemplateOpts): string }> = {
      prSummarizer: PRSummarizerAgent,
      // ... all 7
    };
    ```

    3. For each agent, dispatch a Promise that:
       a. Calls onSectionUpdate(agentKey, { status: 'generating' }) immediately
       b. Calls parseContextRequest(agentTemplate) to get the body and context flags
       c. Builds AgentTemplateOpts with opts.diff, opts.fileList, and conditionally
          opts.projectAnalysis (if contextReq.projectAnalysis) / opts.commitHistory (if contextReq.commitHistory)
       d. Calls the appropriate runner based on resolveAgentModel(agentKey, opts.modelConfig):
          - 'claude': ADK query() with systemPrompt + maxTurns:1 + permissionMode:'bypassPermissions'
                      + pathToClaudeCodeExecutable:opts.claudePath + abortController
          - 'codex': runReview(opts.codexPath, new CodexAdapter(), { prompt, token, onChunk: ()=>{} })
          - 'ollama': new OllamaAdapter().run({ agentKey, prompt, systemPrompt, model: 'ollama', onChunk: ()=>{}, abortSignal, token })
       e. For 'diagram' agent: after result, call validateMermaidSyntax(extractMermaidBlock(result) ?? result)
          - If invalid: run up to 2 correction retries (call agent again with correction prompt)
          - Correction prompt = original prompt + '\n\nPrevious output was invalid:\n' + previousOutput + '\nError: ' + error + '\n\nPlease produce valid Mermaid syntax starting with a recognized type keyword.'
          - After 2 failures: use the raw output; the DiagramErrorBanner is shown in the webview
       f. Calls onSectionUpdate(agentKey, { status: 'complete', content: result }) on success
       g. Calls onSectionUpdate(agentKey, { status: 'error', error: err.message }) on failure

    4. Use Promise.allSettled() over all 7 agent promises (NOT Promise.all — individual agent failures must not abort the pipeline).

    5. Build the final Record<AgentKey, SectionState> from the settled results.

    6. Create a shared AbortController; on token.onCancellationRequested, call controller.abort().

    ADK import (must be runtime-safe after esbuild bundling):
    ```typescript
    // eslint-disable-next-line @typescript-eslint/no-require-imports
    const { query } = require('@anthropic-ai/claude-agent-sdk') as typeof import('@anthropic-ai/claude-agent-sdk');
    ```
    Use require() not import statement because at runtime it's bundled into CJS — TypeScript
    type safety is preserved via the `as typeof import(...)` cast.
